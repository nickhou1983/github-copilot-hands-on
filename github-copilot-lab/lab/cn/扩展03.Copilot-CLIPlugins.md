## GitHub Copilot Lab

### 什么是 Copilot CLI Plugins？

Copilot CLI Plugins 是扩展 Copilot CLI 功能的插件包。通过安装社区或团队创建的插件，你可以为 Copilot CLI 添加新的能力，例如数据库管理、CI/CD 流水线操作、特定框架支持等。

插件通过 **Marketplace（市场）** 进行分发和管理。Marketplace 是插件的注册中心，你可以从中浏览和安装插件。Copilot CLI 默认预注册了两个市场：`copilot-plugins` 和 `awesome-copilot`。

### 核心概念

| 概念 | 说明 |
|------|------|
| Plugin | 扩展 Copilot CLI 功能的独立包 |
| Marketplace | 插件的注册中心/仓库，用于分发和发现插件 |
| copilot-plugins | 官方默认市场 |
| awesome-copilot | 社区精选市场 |

## Lab 步骤

### 第一步：查看已注册的 Marketplace

#### 1.1 目标
了解当前 CLI 中已注册的插件市场

#### 1.2 操作步骤

1. **在终端中查看市场列表**

   ```bash
   copilot plugin marketplace list
   ```

   或者在 Copilot CLI 交互式会话中输入：
   ```
   /plugin marketplace list
   ```

2. **查看输出**

   默认应该能看到两个已注册的市场：
   - `copilot-plugins` — 官方市场
   - `awesome-copilot` — 社区精选市场

#### 1.3 验证
- 命令成功执行并显示已注册的市场列表

---

### 第二步：浏览插件市场

#### 2.1 目标
从已注册的市场中浏览可用的插件

#### 2.2 操作步骤

1. **浏览 awesome-copilot 市场中的插件**

   ```bash
   copilot plugin marketplace browse awesome-copilot
   ```

   或在交互式会话中：
   ```
   /plugin marketplace browse awesome-copilot
   ```

2. **浏览 copilot-plugins 市场**

   ```bash
   copilot plugin marketplace browse copilot-plugins
   ```

3. **查看插件详情**

   浏览列表时，注意每个插件的名称和描述，选择感兴趣的插件准备安装。

#### 2.3 验证
- 成功列出市场中的可用插件
- 能看到插件名称和功能描述

---

### 第三步：安装插件

#### 3.1 目标
从市场安装一个插件并验证安装成功

#### 3.2 操作步骤

1. **安装插件**

   使用 `PLUGIN-NAME@MARKETPLACE-NAME` 格式安装插件。例如，从 `awesome-copilot` 市场安装 `database-data-management` 插件：

   ```bash
   copilot plugin install database-data-management@awesome-copilot
   ```

   或在交互式会话中：
   ```
   /plugin install database-data-management@awesome-copilot
   ```

2. **查看已安装的插件列表**

   确认插件安装成功：
   ```bash
   copilot plugin list
   ```

#### 3.3 验证
- 插件安装命令成功执行
- `copilot plugin list` 输出中可以看到刚安装的插件

---

### 第四步：管理已安装的插件

#### 4.1 目标
掌握插件的更新和卸载操作

#### 4.2 操作步骤

1. **更新插件**

   将已安装的插件更新到最新版本：
   ```bash
   copilot plugin update PLUGIN-NAME
   ```

2. **卸载插件**

   移除不再需要的插件：
   ```bash
   copilot plugin uninstall PLUGIN-NAME
   ```

3. **查看插件帮助**

   获取插件管理的完整帮助信息：
   ```bash
   copilot plugin --help
   ```

#### 4.3 验证
- 能成功更新和卸载插件
- 卸载后 `copilot plugin list` 中不再显示该插件

---

### 第五步：添加自定义 Marketplace

#### 5.1 目标
学习如何注册额外的插件市场

#### 5.2 操作步骤

1. **添加 GitHub 上的市场**

   如果你的团队或社区有自己的插件市场仓库，可以添加到 CLI 中：
   ```bash
   copilot plugin marketplace add OWNER/REPO
   ```

   例如：
   ```bash
   copilot plugin marketplace add anthropics/claude-code
   ```

   或在交互式会话中：
   ```
   /plugin marketplace add OWNER/REPO
   ```

2. **添加本地文件系统的市场**

   如果市场位于本地文件系统：
   ```bash
   copilot plugin marketplace add /PATH/TO/MARKETPLACE-DIRECTORY
   ```

3. **添加非 GitHub 的 Git 仓库市场**

   如果市场托管在其他 Git 平台（如 GitLab）：
   ```bash
   copilot plugin marketplace add https://gitlab.com/OWNER/REPO.git
   ```

4. **验证添加成功**

   ```bash
   copilot plugin marketplace list
   ```

#### 5.3 验证
- 新添加的市场出现在市场列表中
- 可以使用 `browse` 命令浏览新市场的插件

---

### 第六步：移除 Marketplace

#### 6.1 目标
学习如何移除不再需要的插件市场

#### 6.2 操作步骤

1. **移除市场**

   ```bash
   copilot plugin marketplace remove MARKETPLACE-NAME
   ```

   或在交互式会话中：
   ```
   /plugin marketplace remove MARKETPLACE-NAME
   ```

   > **注意**：添加市场时使用的是 `OWNER/REPO` 格式，但移除时使用的是市场在列表中显示的名称。

2. **强制移除有已安装插件的市场**

   如果市场中有已安装的插件，直接移除会失败。使用 `--force` 选项强制移除市场并卸载其中的所有插件：
   ```bash
   copilot plugin marketplace remove MARKETPLACE-NAME --force
   ```

#### 6.3 验证
- 市场成功从列表中移除
- 使用 `--force` 时，相关插件也被一并卸载

## 常用命令速查表

| 命令 | 说明 |
|------|------|
| `copilot plugin marketplace list` | 查看已注册的市场 |
| `copilot plugin marketplace browse NAME` | 浏览市场中的插件 |
| `copilot plugin marketplace add OWNER/REPO` | 添加新市场 |
| `copilot plugin marketplace remove NAME` | 移除市场 |
| `copilot plugin install NAME@MARKETPLACE` | 安装插件 |
| `copilot plugin list` | 查看已安装的插件 |
| `copilot plugin update NAME` | 更新插件 |
| `copilot plugin uninstall NAME` | 卸载插件 |
| `copilot plugin --help` | 查看帮助 |
