# GitHub Copilot Labs 总览

## 基础实验

| Lab | 名称 | 内容概述 |
| ----- | ------ | ---------- |
| 01 | [CopilotAgent](./01.CopilotAgent.md) | 介绍 Copilot 基础能力，并使用 Plan/Agent 模式规划并生成旅游网站 PRD。 |
| 02 | [Copilot-CLIAgent](./02.Copilot-CLIAgent.md) | 学习 Copilot CLI Sessions 的隔离模式与后台会话管理。 |
| 03 | [CustomInstructions](./03.CustomInstructions.md) | 创建并实践项目级与语言级 Instructions（如 TypeScript 规则）。 |
| 04 | [CopilotCLI](./04.CopilotCLI.md) | 使用 Copilot CLI 在终端中完成 Plan 到 Autopilot 的开发流程。 |
| 05 | [Copilot CLI + Superpowers](./05.Copilot%20CLI%20+%20Superpowers.md) | 在 Copilot CLI 中安装并使用 Superpowers 插件，体验流程化开发方法。 |
| 06 | [CustomAgent](./06.CustomAgent.md) | 使用 `/agent` 创建可复用的 Custom Agent（示例：测试用例生成 Agent）。 |
| 07 | [CreateAgentSkill](./07.CreateAgentSkill.md) | 使用 `/create-skill` 创建自定义 Agent Skill 并完善检查规则。 |

## 扩展实验

| Lab | 名称 | 内容概述 |
| ----- | ------ | ---------- |
| 扩展 01 | [AgentSkill](./扩展01.AgentSkill.md) | 启用并安装社区 Agent Skills，体验 Skill 的自动触发与复用。 |

| 扩展 03 | [Copilot-CLIPlugins](./扩展03.Copilot-CLIPlugins.md) | 了解 Copilot CLI 插件市场，完成插件浏览、安装与使用。 |
